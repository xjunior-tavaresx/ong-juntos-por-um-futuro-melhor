🎯 Objetivo do projeto

Desenvolver uma página web simples, organizada e responsiva para representar uma ONG e facilitar o acesso dos visitantes às informações sobre seus projetos e formas de participação.

O site permite conhecer a proposta da organização, visualizar projetos sociais e acessar um formulário para cadastro de voluntários e interessados em realizar doações.

🚀 Como executar o projeto
Faça o download ou clone este repositório.
Abra a pasta do projeto em seu computador.
Abra o arquivo index.html em um navegador.
Utilize o menu de navegação para acessar as demais páginas.

Não é necessária a instalação de dependências ou servidor para executar o projeto.

📱 Responsividade

O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela, incluindo computadores e dispositivos móveis.

Foram utilizadas Media Queries em CSS para realizar os ajustes necessários em telas menores.

📝 Validação do formulário

O formulário utiliza recursos nativos do HTML5 para validação dos dados informados pelo usuário, incluindo campos obrigatórios e padrões de preenchimento.

Entre os dados tratados no formulário estão:

CPF
Telefone
CEP
Informações de participação
